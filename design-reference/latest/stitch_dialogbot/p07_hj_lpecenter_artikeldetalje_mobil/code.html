Sådan installerer du Dialogbot webchat-widget på din hjemmeside

schedule 3 min læsetid • Opdateret 14. okt 2026 • Dialogbot Support
info

Følg de tre trin herunder for at gøre den intelligente AI-receptionist tilgængelig for dine besøgende døgnet rundt.

1

Hent unikt kodesnippet

Kopier nedenstående JavaScript-snippet. Husk at udskifte DIN_OFFENTLIGE_ID med widget-nøglen fundet under dine indstillinger.

code HTML / Javascript 
<!-- Dialogbot Webchat Widget -->
<script>
  window.dialogbotConfig = {
    apiKey: "pub_live_79a2ef490bc1c",
    lang: "da",
    mode: "hybrid_booking"
  };
</script>
<script 
  async 
  src="https://cdn.dialogbot.dk/v2/widget.esm.js">
</script>
2

Indsæt før </body> tagget

Indsæt koden lige før det afsluttende </body> tag. Vælg din platform for præcis placering:

layers WordPress installation expand_more

1. Gå til dit WordPress Kontrolpanel → Udseende → Temafil-editor (eller brug plugin som 'WPCode').

2. Vælg filen footer.php.

3. Indsæt kodesnippet umiddelbart over linjen <?php wp_footer(); ?> eller </body>.

shopping_bag Shopify integration expand_more

1. Log ind på Shopify Admin og gå til Online Store → Themes.

2. Klik på handlinger (...) og vælg Edit code.

3. Find theme.liquid under Layouts og indsæt koden over </body>.

tag Google Tag Manager (GTM) expand_more

1. Opret et nyt tag af typen Brugerdefineret HTML.

2. Indsæt kodesnippet og tilføj triggeren Initialization - All Pages eller All Pages.

3. Gem og udgiv containeren.

3

Godkend domæne i sikkerhedsindstillinger (S05)

Af hensyn til beskyttelse mod uautoriseret brug, blokerer Dialogbot automatisk forespørgsler fra domæner, der ikke er eksplicit hvidlistet.

verified_user Tjekliste til hvidlistning
  1. Gå til Sikkerhedsindstillinger (S05) i din admin portal.
  2. Tilføj dit produktionsdomæne (fx minvirksomhed.dk).
  3. Tilføj eventuelle test- eller staging-miljøer.
warning
Bemærkning om CSP (Content Security Policy)

Hvis din hjemmeside benytter en streng CSP-header, skal du tillade script-src https://cdn.dialogbot.dk samt connect-src https://api.dialogbot.dk wss://stream.dialogbot.dk for at tillade realtids-transskription.
