# Assets for the social post images

- `Outfit-ExtraBold.ttf`, `Outfit-Bold.ttf` — Outfit (Rodrigo Fuenzalida), SIL Open Font License 1.1. Static
  instances (wght 800 / 700, latin + latin-ext) made with fontTools from the variable font the website ships
  (`web/node_modules/@fontsource-variable/outfit`). Outfit is the brand's headline face (docs/brand.md).
- `logo.png` — the brand mark (blue rounded square with the chat bubble) at 512 px, RGBA; a copy of
  `web/public/brand/logo-mark-1024.png` scaled down. Update it when the logo changes.
