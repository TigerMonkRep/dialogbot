## Kort
Quiz-funnelens velkomstmail til en ny Privat-konto («Vælg adgangskode») er blå Erhverv-mail, kun dansk, og linket kører gennem Erhverv-reset → /opsaetning/1. Kontoen får signup_intent NULL, så et senere «Send nyt link» giver Erhverv-bekræftelsesmailen («AI-receptionist», → /onboarding/workspace → /opsaetning/1).

## Trin til at genskabe
1. /privat/start → gennemfør quizzen → SMS-kode → konto oprettes (app/modules/funnel/service.py _new_user: signup_intent="reception" if erhverv else None)
2. _welcome(): tpl.Email(…) uden audience → blå; link /password/reset?token=…
3. Følg linket → som F-JP-02 → /opsaetning/1
4. Senere «Bekræft din e-mail» → POST /auth/verify-email/resend → issue_verification: signup_intent ≠ privat → Erhverv-mail

## Forventet
Velkomstmail i Privat-layout, på brugerens sprog, link der ender i /privat; Privat-funnelkonti markeres som Privat (signup_intent privat), så alle senere kontomails er Privat.

## Faktisk
Blå mail «Velkommen til Dialogbot – vælg din adgangskode», kun dansk; signup_intent NULL → Erhverv-bekræftelsesmail ved gensendelse. #179 rettede kun /signup-vejen.
